# Architecture Decision Records

Short records of decisions that would be expensive to re-argue later: the context that forced
them, the options considered, and why one won. Format: [MADR](https://adr.github.io/adr-templates/).

Numbered sequentially (`0001`, `0002`, ...) and never reused. A superseded ADR stays in place with
its status updated rather than being deleted.
